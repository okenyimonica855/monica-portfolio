# Monica Okenyi — Interactive Portfolio

This is a GitHub Pages-ready static portfolio.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — interactive Nubian Skin case study
- `assets/` — add your portrait, screenshots and other visuals here

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `monica-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a public portfolio URL.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
- Put your portrait in `assets/` and replace the portrait placeholder in `index.html`.
- Add your final CV link when ready.
- Add project screenshots/PDF links after the main structure is approved.

## Design direction
Deep plum / aubergine, warm bone / ivory, muted sage and copper. Editorial typography. No gradients, glassmorphism or generic AI-dashboard styling.

## Nubian Skin case study
The case study is implemented as a 10-slide interactive experience with:
- Previous / Next navigation
- Progress indicator
- Clickable slide dots
- Keyboard arrow navigation
- Responsive layouts
- The simulated-data disclaimer preserved
