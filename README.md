# Monica Okenyi — Interactive Multi-Page Portfolio

This version intentionally uses separate pages rather than one long scrolling page.

Pages:
- `index.html` — short homepage
- `about.html` — About
- `experience.html` — Experience
- `work.html` — Projects
- `nubian-skin.html` — full case study
- `contact.html` — Contact
- `styles.css` — shared styling

Publish through GitHub Pages using `main` and `/ (root)`.

Before publishing, replace `YOUR_EMAIL@example.com` and the portrait placeholder.
