03 · ROOT CAUSE

I investigate before I prescribe.

I would test technical, process, adoption and business hypotheses rather than assuming the problem is simply a training gap.

TECHNICAL

Is sync failing?

Ask Daniel for error patterns, affected workflows and recent configuration changes.

PROCESS

Has the workflow changed?

Ask Operations where work is still being done manually and why.

ADOPTION

Do users trust the workflow?

Review activity, completion and previous enablement before choosing an intervention.

Finding: the evidence points to a technical workflow problem that created an operational spreadsheet workaround and weakened adoption.

04 · 90-DAY PLAN

Stabilise → rebuild adoption → prove value.

DAYS 1–30

Stabilise

Escalate the inventory configuration issue, review tickets, run UAT and retrain affected users.

DAYS 31–60

Rebuild adoption

Monitor WAU and order share, target enablement and re-engage the champion.

DAYS 61–90

Demonstrate value

Compare results to customer goals, review time saved and accuracy, then prepare renewal readiness.
